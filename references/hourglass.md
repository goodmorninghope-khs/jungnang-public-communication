# 커뮤니케이션 전략수립 모래시계 모델

원형: 김현성, 「디지털커뮤니케이션」 강의안(2019) 16번 장표 「커뮤니케이션 전략수립 모래시계 모델」. 같은 강의안의 흐름 "우리는 어디에 있는가? → 어디로 갈 것인가? → 어떻게 갈 것인가?"(문제점과 기회 발견 → 커뮤니케이션 목표 설정 → 전략과 전술)를 세 단계에 겹쳐 쓴다.

## 원형 구조

| 단계 | 이름 | 원형의 칸 | 묻는 질문 |
|---|---|---|---|
| 1단계 (위, 넓게) | 조사 및 환경분석 | Research: 문헌조사·사례조사 등 과학적·객관적 데이터 수집 / Company 내부환경분석 / Condition 홍보 환경 분석 / Consumer 타깃 분석 | 우리는 어디에 있는가? |
| 허리 (좁게) | 홍보컨셉 및 전략 도출 | Concept · Communication Strategy | 어디로 갈 것인가? 어떤 이야기를 해야 하는가? |
| 수단 선택 | (2026 확장) | BRANDING · ISSUE FIGHTING · CAMPAIGN · STORYTELLING · COMMUNITY | 무엇으로 갈 것인가? |
| 2단계 (아래, 넓게) | 홍보 전략 수립 | Contents 콘텐츠 전략 / Channel 매체 전략 / Consumer 타깃 전략 / Crisis Management 위기관리 전략 | 어떻게 갈 것인가? |
| 3단계 (바닥) | 실행 프로그램 도출 | Action Plan: 단계별·연차별 홍보 프로그램 / 주요 이슈별 / 이슈·위기 관리 대응체계 | 무엇을, 언제, 누가 하는가? |

같은 모래시계는 「중랑 정책셰프 5중 필터」에서 정책 선정 필터로도 쓰인다(넓게 조사했는가 / 핵심을 좁혔는가 / 사람이 움직이는가). 넓히고, 좁히고, 다시 펼친다는 뼈대가 같다.

뜻·땀·때(10.01 특강 확정본, 원형은 「소통령」 원고의 志·汗·時)를 겹치면: 뜻(누구의 어떤 불편을 풀 것인가) = 허리, 땀(현장에서 묻고 연결하고 고쳐 보는 일) = 1단계 듣는 조사와 3단계 실행, 때(주민이 필요한 순간에 닿는 일) = CONTEXT와 실행 시점.

2026년 「맛있는 커뮤니케이션」의 레시피는 이 모래시계 위에 얹힌다. 1단계의 3C는 재료 준비, 허리는 양념과 컨셉, 수단 선택은 메뉴 고르기, 2·3단계는 끓이기, ROI는 세 번의 간보기다.

## 1단계 작업표 · 넓게 모은다

넓게 모으되 각 칸을 세 줄 안팎으로 요약하라. 출처와 확인 날짜를 붙여라.

| 칸 | 모을 것 | 체크 질문 |
|---|---|---|
| Research | 관련 법령·예산·통계, 언론 보도, 타 지역 사례, 민원 반복 패턴, 공식 채널 밖의 데이터 | 공식 채널에 0건이라고 수요가 없다고 단정하지 않았는가 |
| Company | 정책의 실체와 근거, 이미 한 일, 조직·인력, 약점과 한계 | 말할 수 있는 실체가 있는가, 홍보가 실체보다 앞서지 않는가 |
| Condition | 여론 흐름, 경쟁 이슈, 시기(天)·장소(地)·사람(人), 이해관계자 지도 | 지금이 때인가, 이 이슈를 덮을 다른 뉴스는 없는가 |
| Consumer | 대상 주민의 장면, 미디어 습관, 신뢰하는 사람, 멈추는 지점 | 주민을 한 덩어리가 아니라 장면별로 쪼갰는가 |
| 듣는 조사 | 당사자·반대자 인터뷰, 청책형 토론, 현장 방문 기록([listening.md](listening.md)) | 이해관계자가 의제 설정 단계부터 들어왔는가 |

마무리: 경험격차 두 층(알림과 이용 사이 / 주민 사이), 전달 4관문(발견 → 이해 → 신청 → 이용) 중 끊긴 곳, 주민의 첫 접점, 문제점과 기회(SWOT를 쓴다면 기회와 위협을 커뮤니케이션 관점으로) 각 한 줄.

## 허리 · 좁히는 법

넓게 모은 것에서 버릴 것을 먼저 고른다. 좁히지 못하는 이유는 대개 모두에게 모든 것을 말하려 해서다.

1. 이번에 바꿀 것 하나: 인식인가, 행동인가, 기억인가, 관계인가, 정체성인가 → 수단 후보가 좁혀진다.
2. 가장 큰 격차 하나: CONTENT(뜻을 모른다)·CHANNEL(본 적이 없다)·COMMUNITY(믿지 않는다) 중 어디인가 → 2단계의 무게중심이 정해진다.
3. 양념 한두 개 → 컨셉의 장치가 정해진다.
4. 컨셉 한 문장: "[누구]가 [어떤 장면]에서 [무엇을] 하게/느끼게/기억하게 한다, [어떤 장치]로."
5. 컨셉에서 주민에게 건넬 한 문장을 뽑는다.

허리 다음에 수단을 고른다([menus.md](menus.md)의 수단별 ROI 비교표).

허리 점검: 컨셉 한 문장으로 2단계의 네 갈래와 3단계의 모든 프로그램을 설명할 수 있는가. 설명되지 않는 전술은 빼라.

## 2단계 · 펼치는 법

| 갈래 | 할 일 | 결과물 |
|---|---|---|
| Contents | 정보를 의미로 번역, 핵심 메시지 1개와 보조 메시지 2~3개, 증거(사람·장면·숫자) | 메시지 하우스, 주민용 한 문장 |
| Channel | POE 트리플 미디어(Paid·Owned·Earned)와 생활 접점(창구·고지서·현장·이웃)을 함께 배치. Mobile First, 짧은 영상·라이브·AI 안내 고려 | 채널 지도(접점 × 시점) |
| Consumer / Community | 타깃별 메시지 변주가 아니라 접근성 변주(쉬운 말·다국어·음성). 공동제작자와 믿는 목소리(AUTHORITY) 지정 | 파트너 명단(역할만, 실명은 확인 후) |
| Crisis | 예상 질문·반론 10개, 오해 지점, 실패 시나리오, 대응 원칙과 화자 | 예상 Q&A, 위기 대응 원칙 |

## 3단계 · 실행 프로그램 표

| 시기 | 프로그램 | 목표 행동 | 채널·접점 | 담당 | ROI 지표 |
|---|---|---|---|---|---|
| 준비 | | | | | |
| 출시 | | | | | |
| 확산 | | | | | |
| 정착 | | | | | |

주요 이슈별 대응: 이슈 / 예상 시점 / 꺼낼 콘텐츠 / 화자.
위기 대응체계: 감지(누가 무엇을 보고) → 판단(누가) → 1차 입장(몇 시간 안에, 누구 명의로) → 후속 조치와 설명.
작게 먼저: 90일 시범 → 데이터 확인 → 개선·확장 → 제도로 남기기. 법 없이 만든 것은 법 없이 사라진다.

## 걸음 예시(가상 사례)

이슈: 무더위쉼터를 늘렸는데 어르신 이용이 적다.

- 1단계: Company 쉼터 ○○곳 운영 / Condition 폭염 특보 예보 / Consumer 홀몸 어르신은 안내문보다 경로당 친구·통장 말을 믿고, 쉼터가 "모르는 사람들 있는 곳"이라 꺼린다. 경험격차: 행정은 쉼터를 열었다 ↔ 어르신은 갈 곳이 없다.
- 관문 ① 판독: R 높음(구청 책임 사업) · O 보통(전국 공통 이슈) · I 보통 → 공세. 지금 꺼낸다.
- 허리: 바꿀 것은 행동(더운 오후에 쉼터로 간다). 양념 FRAME(쉼터 → '동네 시원한 사랑방') + NUDGE(통장이 첫 방문을 함께 걷는다). 컨셉: "어르신이 더운 오후 두 시, 아는 얼굴과 함께 동네 사랑방으로 간다."
- 수단 선택(관문 ②):

| 수단 | R | O | I | 판단 |
|---|---|---|---|---|
| BRANDING | 1 | 2 | 1 | 이름 바꾸기는 양념(FRAME)으로만 쓴다 |
| ISSUE FIGHTING | 1 | 1 | 1 | 이미 공감된 문제, 의제화 불필요 |
| CAMPAIGN | 3 | 2 | 2 | 주 수단: 첫 방문 행동을 만든다 |
| STORYTELLING | 2 | 2 | 1 | 2차: 첫 이용 어르신 이야기로 확산 |
| COMMUNITY(NETWORKING) | 3 | 2 | 3 | 보조 수단: 통장·경로당이 함께 모신다 |

  주 수단 CAMPAIGN, 보조 COMMUNITY. STORYTELLING은 확산 단계로 미룬다.
- 2단계: Contents "두 시엔 사랑방" / Channel 경로당·통장 방문·폭염 문자 / Community 통장·경로당 회장 / Crisis 쉼터 혼잡, 냉방 고장 대응.
- 3단계: 한 동에서 2주 시범 → 이용자 수·재방문율 확인 → 전 동 확산.
- 관문 ③ 지표: 쉼터 이용 어르신 수, 재방문율, 온열질환 신고 건수(측정 계획).
- 주민 문장: "어르신, 오늘 두 시에 ○○경로당 사랑방에서 시원한 보리차 드세요. 통장님이 모시러 갑니다."
