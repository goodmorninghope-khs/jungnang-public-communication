# 다섯 수단 플레이북

사례의 출처와 쪽수는 [사례 창고](cases.md)에 있다.

모래시계의 허리에서 컨셉을 정한 뒤, 그 컨셉을 실현할 수단을 다섯 가운데서 고른다. 고른 수단의 플레이북으로 2단계 전략과 3단계 실행 프로그램을 채운다.

## 수단 고르기 순서

1. 아래 진단표에서 1단계 진단과 맞는 줄을 찾아 후보를 좁힌다.
2. 다섯 수단 모두에 대해 R·O·I 비교표를 채운다(관문 ②).
3. 주 수단 하나, 필요하면 보조 수단 하나. 점수는 참고하고, 최종 기준은 1단계의 가장 큰 격차다. 역할과 순서를 적는다.
4. 고르지 않은 수단의 이유를 한 줄씩 남긴다.

### 수단별 ROI 비교표

| 수단 | R 주민에게 내 이야기가 되는가 | O 우리만의 방식인가 | I 바꾸려는 것이 실제로 바뀌는가 | R×O×I | 판단 |
|---|---|---|---|---|---|
| BRANDING | | | | | |
| ISSUE FIGHTING | | | | | |
| CAMPAIGN | | | | | |
| STORYTELLING | | | | | |
| COMMUNITY(NETWORKING) | | | | | |

관문 ① 판정과의 연결: 공(攻)이면 ISSUE FIGHTING·CAMPAIGN이 앞에, 수(守)면 설명과 위기관리를 바탕으로 STORYTELLING·COMMUNITY를 먼저 검토한다. 보류면 다른 의제의 수단 안에 조각으로 넣는다.

## 수단 진단표

| 1단계에서 이런 진단이 나오면 | 주 수단 후보 | 자주 붙는 보조 수단 |
|---|---|---|
| 기관·장소·사업의 정체가 흐릿하거나 낡은 이름에 갇혀 있다 | BRANDING | STORYTELLING |
| 주민이 겪는 문제가 개인 탓·남의 일로 여겨지고 공적 의제가 아니다 | ISSUE FIGHTING | CAMPAIGN |
| 무엇을 해야 하는지는 정해졌는데 주민이 하지 않는다(신청·참여·준수) | CAMPAIGN | COMMUNITY |
| 성과는 있는데 기억되지 않는다, 숫자만 있고 사람이 없다 | STORYTELLING | BRANDING |
| 장소·사람·자원은 있는데 서로 이어지지 않는다, 행정 혼자 한다 | COMMUNITY(NETWORKING) | CAMPAIGN |

순서가 있는 경우: 낯선 문제는 ISSUE FIGHTING으로 의제를 세운 뒤 CAMPAIGN으로 행동을 만들고, STORYTELLING으로 기억시키고, 쌓이면 BRANDING이 된다. COMMUNITY는 모든 단계를 가로지른다. 한 번의 기획에서는 지금 단계의 수단 하나에 집중한다.

## BRANDING · 우리는 어떤 곳으로 기억될까

- 언제: 이름·정체성이 실체를 담지 못할 때, 새 조직·공간·사업을 출범할 때
- 허리 공식: "[대상]은 [주민에게] [어떤 곳/존재]다." 약속 하나로 요약
- 주 양념: FRAME(이름과 액자 바꾸기), CONTEXT
- 전술: 이름 짓기, 정체성 문장, 시각 체계, 대표 경험 하나(첫 방문의 장면), 내부 구성원이 먼저 쓰는 말. 기관장 브랜드라면 PI(실제 모습·의도한 정체성·인식된 이미지의 교집합 넓히기)로 접근하고, 보이는 모든 것이 해석된다는 점을 전제로 등장 장소·동행·소품을 고른다
- I 지표: 이름 인지와 연상, 자발적 사용(주민·언론이 새 이름으로 부르는가), 방문·이용
- 실패: 로고·슬로건만 바꾸고 실체·경험은 그대로. 브랜딩을 단기 캠페인처럼 끓이기. 실체 없는 이미지 포장은 기술만 있고 내용이 없는 선전이 된다(『물음』 44~45쪽)
- 사례: 시민청(廳 → 聽), 청책(聽策)이라는 새 말, PI 사례, 망우리 공동묘지 → 망우역사문화공원, AI지원팀 → AI혁신팀

## ISSUE FIGHTING · 어떤 불편을 공적 의제로 다룰까

- 언제: 주민이 겪는 문제가 아직 공적 의제가 아닐 때, 구조적 원인을 드러내야 할 때
- 허리 공식: "[개인의 습관·사정]이 아니라 [도시·제도가 함께 풀 문제]다." 지금의 이름 → 우리가 세우는 의제
- 주 양념: FRAME, INSIGHT(숨은 데이터), RULE(제도 대안)
- 전술: 문제의 이름 붙이기, 결정적 숫자와 한 사람의 장면, 당사자의 목소리, 제도 대안 제시, 연대 선언
- 관문 ① 판독이 특히 중요하다: 공/수 판단, 상대방의 반론 예상. 적과 라이벌이 생겨야 내가 규정된다. 다만 상대는 사람이 아니라 문제와 구조로 잡는다
- 위기 규칙: 공격 프레임을 반복해 부인하지 않는다. 신념과 근거로 논의의 중심을 옮긴다
- I 지표: 언론·의회 의제화, 제도·예산 반영, 당사자 참여 규모
- 실패: 문제 정의 없이 해법 홍보, 특정 인물·집단을 겨냥한 네거티브(쓰지 않는다)
- 사례: 공(攻) 노숙인 사망 → 희망온돌 청책토론회, 배민 독립선언(사장님 1,547명, 1,000인 서명 5일), 금연의 사회 의제화 / 수(守) 영등포 반값식당 잠정 보류 / [제안] 도파민 쉼터, 중랑교쇼핑센터 '촉 → 혈자리 → 침'

## CAMPAIGN · 어떤 행동을 함께 바꿀까

- 언제: 목표 행동이 분명하다(신고·신청·참여·준수·중단)
- 허리 공식: 목표 행동을 동사 하나로. "[누가] [언제] [무엇을] 한다." 행동의 문턱을 낮출 장치 하나
- 주 양념: NUDGE, RULE(기본값 바꾸기), CONTEXT(행동이 필요한 순간에 도착)
- 전술: 행동이 일어나는 순간의 접점 공략(창구·고지서·문자 타이밍), 기한과 리마인드, 쉬운 신청 경로(QR), 참여 보상, 단계별 집행(준비-출시-확산-정착)
- I 지표: 목표 행동의 전후 변화, 단계별 이탈률
- 대상을 좁혀라. 전 국민을 대상으로 하면 애매한 광고가 된다. 대상이 이미 아는 사실(담배는 해롭다)을 반복하지 말고 대상이 구체적으로 신경 쓰는 것(입 냄새, 피부)을 드러내라
- '하지 마라'보다 '같이 하자'가 어렵고, 그래서 더 설계가 필요하다(『물음』 50쪽). 행동의 문턱은 내 방 문턱처럼 낮아야 한다(1트윗 = 1원)
- 실패: 목표가 "관심 갖기"처럼 흐릿함, 겁주기만 하는 메시지, 혐오 영상
- 사례: 금연광고 「자학」·「이별」, 1트윗 = 1원, 아름다운재단 1%, 노인요양제도 광고, QR광주, 하이파이브, [제안] AI Challenge Credit

## STORYTELLING · 어떤 사람과 장면을 기억하게 할까

- 언제: 실적은 있는데 기억되지 않을 때, 정책의 의미를 전해야 할 때
- 허리 공식: "[한 사람]이 [어떤 장면]에서 [어떻게 달라졌다]." 숫자 대신 사람, 설명 대신 장면
- 주 양념: CONTEXT, INSIGHT
- 전술: 주인공 찾기(동의 필수), 장면 하나로 시작하는 콘텐츠, 연재·루틴(아궁이 7AM, 시그널), 당사자가 직접 말하는 형식
- I 지표: 회상·공유, 당사자의 참여 확대, 후속 문의
- 실패: 실적 나열, 취약한 주민의 사정을 이미지 장치로 소비, 만든 이야기
- 스토리텔링은 수단이고, 맥락(CONTEXT)은 양념이다. 둘을 섞지 않는다
- 사례: 제돌이(이름 있는 한 마리, 표지석 '제돌이의 꿈은 바다였습니다'), 시민발언대 '할 말 있어요', 떡볶이집 사장님 강사, 가상 시민 '서울씨', [제안] 「구청에 AI가 출근했다」

## COMMUNITY(NETWORKING) · 누구와 어떤 관계를 이어갈까

10.01·10.15 특강에서는 NETWORKING이라 부른다. 수단으로서의 COMMUNITY는 관계를 이어가는 목적이고, 재료의 COMMUNITY(함께 만들고 쓰고 고칠 사람)와 구분한다. 성과는 조회수가 아니라 협력 관계가 실제로 이어졌는지에서 찾는다. 이해관계자는 결과 설명 단계가 아니라 의제 설정 단계부터 참여시킨다([경청과 청책](listening.md)).

- 언제: 자원·장소·사람은 있는데 이어지지 않을 때, 행정 혼자로는 지속이 안 될 때
- 허리 공식: "[누구]와 [누구]를 [어떤 장소·시간]에 이어 [무엇을] 함께 만든다."
- 주 양념: INSIGHT(누가 이미 하고 있는가), RULE(참여의 구조), FRAME(수혜자 → 주인공)
- 전술: 청책 7단계, 공동제작자 모집(내부 공모 포함), 정례 모임과 응답 통로, 파트너 역할 표, 연결 동선 설계, 현장 3.3.3과 사후관리 123, 누가누배(누구나 가르치고 누구나 배운다)
- I 지표: 참여자 수와 재참여, 시민 의견 채택률과 회신(메아리), 주민 주도 활동 수, 사업 종료 후에도 남는가
- 실패: 행사 한 번으로 끝, 행정이 선수 노릇, 응답 없는 의견 수렴
- 사례: 청책토론회(책 읽는 서울·인생이모작·동네경제), 2030 서울플랜 시민 160번 회의, 현장시장실, 명예부시장, 정책아이디어마켓, 제돌이 시민위원회 12차례, 청책 시민 10만 명, 가치삽시다, [제안] NIGHT LOOP·Small AI·AI 파트너즈
